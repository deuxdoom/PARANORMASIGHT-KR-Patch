지원 환경과 설치

Windows용 Steam판 한국어 패치 v1.0.0을 제공합니다.

지원 환경

  • Windows 10/11 64비트 Steam판 기준입니다 (Steam AppID 2106840).
  • Nintendo Switch, iOS, Android판과 Steam 이외의 PC판은 지원하지 않습니다.
  • 게임을 정상적으로 구매해 설치한 상태여야 합니다. 수정한 게임 파일 13개와 글꼴 고지를 포함하며, 게임 전체·수정하지 않은 원본 파일·Steam 구성 파일은 포함하지 않습니다.

설치 방법

  1. 게임을 종료하고 Steam 게임 속성 → 일반 → 언어를 日本語(일본어)로 설정합니다.
  2. PARANORMASIGHT1_KR_v1.0.0_Setup.exe를 실행합니다.
  3. 기본 경로는 C:\Program Files (x86)\Steam\steamapps\common\PARANORMASIGHT입니다. 다른 위치라면 찾아보기로 게임 폴더를 선택합니다.
  4. 설치가 끝나면 완료를 눌러 닫고 게임을 실행합니다.

기존 패치는 먼저 제거하지 않고 같은 폴더에 다시 설치할 수 있습니다. 파일 크기는 약 316MB이며, 자세한 파일 정보는 v1.0.0 릴리스를 참고해 주세요.

제거·복원

Windows 설치된 앱에서 파라노마사이트1 한국어 패치를 제거하거나 게임 폴더의 unins000.exe를 실행합니다. 기존 .bak은 보존하며, 새 백업은 제작 기준 원본과 일치하는 파일만 만듭니다. 제거하면 남아 있는 백업을 복원합니다.

.bak이 없는 설치 대상은 삭제되므로 원본이 필요하면 Steam의 게임 파일 무결성 확인을 이용해 주세요.

자주 묻는 질문

패치를 쓰기 전에 알아 두면 좋은 내용입니다.

어디서 내려받나요?

상단의 1편 설치파일 버튼이나 v1.0.0 릴리스에서 정식 설치 파일을 내려받을 수 있습니다.

Switch나 모바일판에서도 쓸 수 있나요?

아니요. Windows용 Steam판만 지원합니다.

2편 패치와 함께 써도 되나요?

각 게임 폴더에 해당 작품의 패치를 따로 설치하면 됩니다. 2편 패치는 그대로 쓰면 됩니다.

퀴즈 정답 안내도 있나요?

퀴즈 정답 안내(QNA_1.md)에서 직접 입력하는 네 문제의 권장 입력을 확인할 수 있습니다. 스포일러가 있으므로 막힌 문제만 펼쳐 보세요.

어떤 글꼴을 쓰나요?

패치에 쓰는 글꼴입니다. 글꼴 원본은 수정하지 않았고, 배포 파일의 Font-Licenses.txt에 각 라이선스 원문을 함께 넣었습니다.

  • Steam 빌드 22496791을 기준으로 만들었습니다. 게임이 업데이트되면 새 판본을 지원하는 패치가 나올 때까지 기다려 주세요.
  • Nintendo Switch, iOS, Android판과 Steam 이외의 PC판은 지원하지 않습니다.
  • 게임을 정상적으로 구매해 설치한 상태여야 합니다. 배포 파일에는 번역을 적용해 수정한 파일만 들어 있으며, 원본 게임 파일은 포함하지 않습니다.

되돌리기

  • Steam 라이브러리에서 게임의 속성 → 설치된 파일 → 게임 파일 무결성 확인을 실행하면 원래 파일로 돌아갑니다.
  • Windows 설정의 설치된 앱에서 파라노마 사이트2 한국어 패치를 제거하면 패치 파일을 지우고 .bak을 원래 이름으로 복원합니다.
  • 기존 .bak은 유지하며, 새 백업은 원본과 일치하는 파일만 만듭니다. 백업이 없는 파일은 제거 후 Steam 무결성 확인으로 복구해 주세요.

설치 방법

게임을 종료하고 Steam 언어를 日本語(일본어)로 설정해 주세요. 기존 버전은 먼저 제거하지 않고 같은 게임 폴더에 설치하면 됩니다.

  1. Steam 게임 속성 → 일반 → 언어를 日本語(일본어)로 바꾸고 내려받기가 끝날 때까지 기다립니다.
  2. PARANORMASIGHT2_KR_v1.0.2_Setup.exe를 실행하고 설치 확인에 동의합니다.
  3. 기본 경로는 C:\Program Files (x86)\Steam\steamapps\common\PARANORMASIGHT_2입니다. 다른 위치라면 찾아보기로 게임 폴더를 선택합니다.
  4. 설치가 끝나면 완료를 눌러 닫고 게임을 실행합니다.

자주 묻는 질문

패치를 쓰기 전에 알아 두면 좋은 내용입니다.

어디서 내려받나요?

상단의 한글패치 설치파일 버튼이나 GitHub Releases에서 내려받을 수 있습니다. 정식 v1.0.2 설치 파일을 제공합니다.

패치를 지우고 원래대로 되돌리고 싶어요.

Windows 설정의 설치된 앱에서 파라노마 사이트2 한국어 패치를 제거하면 남아 있는 .bak을 복원합니다. 백업이 없는 파일은 삭제되므로 제거 후 Steam의 게임 파일 무결성 확인으로 원본을 복구해 주세요.

Switch나 모바일판에서도 쓸 수 있나요?

아니요. Windows용 Steam판만 지원합니다.

Steam 업데이트 뒤에 일본어로 돌아왔어요.

Steam의 게임 파일 무결성 확인이나 게임 업데이트가 패치한 파일을 원래대로 되돌릴 수 있습니다. 게임이 업데이트되면 새 판본을 지원하는 패치가 나올 때까지 기다려 주세요.

자료 화면의 줄바꿈이 어색한 곳이 있어요.

자료의 문장 흐름과 제보된 그림·출처 배치를 수정했습니다. 최신 수정 화면의 추가 확인과 전체 분기 플레이 검증은 계속 수집합니다. 어색한 줄바꿈이나 진행 문제는 자료 이름·장면과 함께 제보해 주세요.

그림 속 일본어가 일부 남아 있어요.

진행에 필요한 제목·안내·단서만 한글화하고, 그림의 장식이나 작은 옛 글씨는 원화 그대로 두었습니다. 읽어야 진행할 수 있는 글자가 일본어로 남아 있다면 제보해 주세요.
